OBJETIVO
----------------------------------------------------------------
Ler uma matriz quadrada de ordem N. Somar somente os elementos
que estão ACIMA da diagonal principal (elementos em que a coluna
é maior que a linha) e mostrar o total.

FUNCIONAMENTO GERAL
----------------------------------------------------------------
1. O usuário informa a ordem (N) da matriz.
2. O programa lê um elemento por vez (índices começando em 0).
3. Percorre toda a matriz: quando a coluna j for maior que a
   linha i, o elemento está acima da diagonal e é somado.
4. Ao final, imprime "SOMA DOS ELEMENTOS ACIMA DA DIAGONAL
   PRINCIPAL = total".

----------------------------------------------------------------
                          CÓDIGO
----------------------------------------------------------------

n = int(input("Qual a ordem da matriz? "))

matriz = []

for i in range(n):
    linha = []

    for j in range(n):
        elemento = int(input(f"Elemento [{i}, {j}]: "))
        linha.append(elemento)

    matriz.append(linha)

soma = 0

for i in range(n):
    for j in range(n):
        if j > i:
            soma += matriz[i][j]

print(f"SOMA DOS ELEMENTOS ACIMA DA DIAGONAL PRINCIPAL = {soma}")

================================================================

OBJETIVO
----------------------------------------------------------------
Ler um inteiro N e uma matriz quadrada de ordem N. Mostrar a
diagonal principal da matriz e a quantidade de valores negativos.

FUNCIONAMENTO GERAL
----------------------------------------------------------------
1. O usuário informa a ordem (N) da matriz.
2. O programa lê um elemento por vez (índices começando em 0).
3. Os elementos em que a linha é igual à coluna (matriz[i][i])
   formam a diagonal principal e são impressos.
4. Depois, o programa percorre toda a matriz e conta quantos
   valores são negativos, imprimindo o total.

----------------------------------------------------------------
                          CÓDIGO
----------------------------------------------------------------

n = int(input("Qual a ordem da matriz? "))

matriz = []

for i in range(n):
    linha = []

    for j in range(n):
        elemento = int(input(f"Elemento [{i}, {j}]: "))
        linha.append(elemento)

    matriz.append(linha)

contador = 0

print("DIAGONAL PRINCIPAL:")

for i in range(n):
    print(matriz[i][i])

for i in range(n):
    for j in range(n):
        if matriz[i][j] < 0:
            contador += 1

print(f"Total de negativos: {contador}")

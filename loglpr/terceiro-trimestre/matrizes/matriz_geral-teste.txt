OBJETIVO
----------------------------------------------------------------
Trabalhar com uma matriz quadrada de ordem N com números reais,
executando estas ações:
a) somar e imprimir os elementos positivos;
b) ler o índice de uma linha e imprimir seus elementos;
c) ler o índice de uma coluna e imprimir seus elementos;
d) imprimir a diagonal principal;
e) elevar ao quadrado os elementos negativos e imprimir a matriz
   alterada.

FUNCIONAMENTO GERAL
----------------------------------------------------------------
1. O usuário informa a ordem (N) da matriz e digita os elementos.
2. Percorre a matriz somando os valores positivos (maiores que 0).
3. Lê o índice de uma linha e mostra os elementos dela.
4. Lê o índice de uma coluna e mostra os elementos dela.
5. Mostra a diagonal principal (linha == coluna).
6. Percorre a matriz: todo elemento negativo é elevado ao
   quadrado (valor ** 2). Depois mostra a matriz alterada.

----------------------------------------------------------------
                          CÓDIGO
----------------------------------------------------------------

n = int(input("Qual a ordem da matriz? "))

matriz = []

for i in range(n):
    linha = []

    for j in range(n):
        elemento = float(input(f"Elemento [{i}, {j}]: "))
        linha.append(elemento)

    matriz.append(linha)

soma_positivos = 0

for i in range(n):
    for j in range(n):
        if matriz[i][j] > 0:
            soma_positivos += matriz[i][j]

print(f"SOMA DOS POSITIVOS: {soma_positivos}")

linha_escolhida = int(input("Escolha uma linha: "))

print("LINHA ESCOLHIDA:")

for j in range(n):
    print(matriz[linha_escolhida][j])

coluna_escolhida = int(input("Escolha uma coluna: "))

print("COLUNA ESCOLHIDA:")

for i in range(n):
    print(matriz[i][coluna_escolhida])

print("DIAGONAL PRINCIPAL:")

for i in range(n):
    print(matriz[i][i])

for i in range(n):
    for j in range(n):
        if matriz[i][j] < 0:
            matriz[i][j] = matriz[i][j] ** 2

print("MATRIZ ALTERADA:")

for i in range(n):
    for j in range(n):
        print(matriz[i][j])

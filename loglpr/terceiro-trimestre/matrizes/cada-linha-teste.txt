OBJETIVO
----------------------------------------------------------------
Ler uma matriz quadrada de ordem N informada pelo usuário e
mostrar o maior valor de cada linha da matriz.

FUNCIONAMENTO GERAL
----------------------------------------------------------------
1. O usuário informa a ordem (N) da matriz.
2. O programa lê um elemento por vez (índices começando em 0).
3. Cada elemento digitado é armazenado na sua linha e coluna.
4. Ao final, o programa percorre as linhas e imprime o maior
   valor encontrado em cada uma.

----------------------------------------------------------------
                          CÓDIGO
----------------------------------------------------------------

N = int(input("qual a ordem da matriz? "))

matriz = []
for i in range(N):
    linha = []
    for j in range(N):
        valor = int(input(f"elemento [{i},{j}]: "))
        linha.append(valor)
    matriz.append(linha)

for linha in matriz:
    print(max(linha))
